🌐 **Demo en vivo:** [eve-bri.github.io](https://eve-bri.github.io)

---

## 🛠️ Tecnologías y Herramientas

* **Frontend:** React JS, JavaScript (ES6+), HTML5, CSS3 / Tailwind CSS.
* **Despliegue & CI/CD:** GitHub Pages, GitHub Actions, `gh-pages` CLI.
* **Control de Versiones:** Git & GitHub.

---

## ✨ Características Principales

* **Soporte Dark / Light Mode:** Transición fluida de temas optimizada con Tailwind CSS.
* **Experiencia Dinámica:** Cálculo automático de años de experiencia profesional desde agosto de 2022.
* **Diseño Responsivo:** Adaptado mediante arquitectura *Mobile-First*.
* **UI/UX Personalizada:** Iconografía e interfaz optimizada sin dependencias pesadas de terceros.
